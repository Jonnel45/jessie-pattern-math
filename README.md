# Jessie's Pattern Math Lab v2

Interactive iPad-friendly maths site for repeating-pattern problems.

## Learning flow
1. Understand the question
2. Discover the operation through visual grouping
3. Learn the calculation method
4. Solve the whole question
5. Summarise the strategy
6. Test the thinking process

## Deploy
Upload `index.html`, `vercel.json`, and this `README.md` to the **root** of the GitHub repository. Replace the old files and commit. Vercel will redeploy automatically.
