# Jessie's Pattern Math Lab

An iPad-friendly interactive maths learning site for repeating-pattern word problems.

## Files

- `index.html` — the complete interactive site
- `vercel.json` — Vercel static-site configuration

## Deploy to Vercel

1. Create a GitHub repository, e.g. `jessie-pattern-math`.
2. Upload `index.html` and `vercel.json` to the **root** of the repository.
3. In Vercel, choose **Add New → Project** and import the GitHub repository.
4. Leave the root directory as `./`.
5. Framework preset: **Other** (or let Vercel auto-detect the static site).
6. No build command is required.
7. Deploy.

Every future push to the connected GitHub repository will trigger a new Vercel deployment.
